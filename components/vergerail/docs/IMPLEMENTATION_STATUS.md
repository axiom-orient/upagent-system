# Vergerail 구현 현황

현재 책임·owner·실행 경계는 [ARCHITECTURE](ARCHITECTURE.md), 공개 계약은
[SPEC](SPEC.md)과 [프로토콜 계약](PROTOCOL_CONTRACT.md)이 설명한다.
본 문서는 제품별 정본 색인이며 상세를 복제하지 않는다.

| 정본 | 역할 |
|---|---|
| [정체성](IDENTITY_AND_EVOLUTION.md) | 목적·보존 조건·발전 원칙 |
| [SPEC](SPEC.md) | 필수·선택 계약 및 원본 참조 |
| [ARCHITECTURE](ARCHITECTURE.md) | 경계·owner·실행 모델 |
| [PLAN](PLAN.md) | 남은 검증·결정 |

현재 소스의 정적 검사·Rust 검증·남은 실행 범위는
[루트 Current](../../../docs/IMPLEMENTATION_STATUS.md)에 기록한다. 첨부된 실행 로그는
수신한 과거 증거이며 현재 소스의 검증으로 승격하지 않는다.
