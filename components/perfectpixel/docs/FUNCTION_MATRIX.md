## 해석·실패 경계

agent-* PARTIAL은 working sRGB 선언과 임의 입력 색 provenance의 경계가 결정되지 않았다는 뜻이다. 일반 inspect의 codec-observed PixelSpec/ICC 처리를 agent-inspect에도 있다고 주장하지 않는다. 알려진 byte/geometry/receipt 동작을 삭제하거나 의미를 바꾸지는 않았다.

일반 Operation의 CLI/MCP presentation과 agent-* 직접 handler는 현재 다른 경로다. 정렬 여부는 [PLAN](PLAN.md)에서 결정한다. 외부 process success는 candidate일 뿐이며 현재 identity, verification, checked publication까지 통과해야 제품 출력이다. 취소·stale·검증 실패 결과는 게시할 수 없다.

색 변환·SSIMULACRA2·SAM 등의 미지원 범위와 KTX/Vision의 선택 조건은 [CONTRACT](CONTRACT.md)와 [OPERATIONS](OPERATIONS.md)를 참조한다.
