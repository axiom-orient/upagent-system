Local image tool

이미지 작업을
정확하게.

PerfectPixel은 사진과 스프라이트를 정리하고, 조건을 통과한 SVG와 모션 파일을 만드는 로컬 도구입니다. 파일은 내 컴퓨터 밖으로 나가지 않습니다.

시작하기 사용 방법 보기
LOCAL · DETERMINISTIC · RUST

복잡한 이미지 작업을
작은 순서로 나눕니다.

좋은 도구는 일을 대신 숨기지 않습니다. 입력 파일을 보고, 필요한 변환을 하고, 결과를 확인할 수 있어야 합니다. PerfectPixel은 이 순서를 명확하게 보여 줍니다.

01 / INSPECT

먼저 확인

이미지의 크기·형식·투명도처럼 작업 전에 알아야 할 사실을 JSON으로 확인합니다.

02 / CONVERT

필요한 모양으로 변환

PNG·JPEG·WebP를 바꾸거나 크기를 조절합니다. 픽셀 아트에는 흐려지지 않는 확대 방식도 있습니다.

03 / BUNDLE

스프라이트로 묶기

여러 프레임을 정리해 아틀라스, 매니페스트, Aseprite JSON까지 한 묶음으로 만듭니다.

04 / PSD + VECTOR + MOTION

편집 가능한 결과로 마무리

투명도를 보존한 PSD와 품질 조건을 통과한 SVG·모션 파일을 만듭니다. PSD 경로도 함께 기록됩니다.

입력부터 결과까지,
무슨 일이 일어나는지 압니다.

이미지 편집은 결과만 맞아도 충분하지 않을 때가 많습니다. 같은 입력이면 같은 결과가 나와야 하고, 실패하면 이전 파일이 망가지지 않아야 합니다.

INPUT원본 파일PNG, JPEG, WebP 또는 작업 요청 파일을 준비합니다.
→
PROCESSPerfectPixel형식과 범위를 확인한 뒤, 정해진 방식으로 처리합니다.
→
OUTPUT결과 파일변환 이미지, 스프라이트 묶음, SVG 또는 모션 결과를 받습니다.
Your files stay with you

이미지는 업로드하지 않습니다.

  • 계정, 로그인, 클라우드 저장소가 필요 없습니다.
  • 명령은 로컬 파일만 읽고 결과도 내가 고른 위치에 씁니다.
  • 작업을 시작하기 전 조건을 확인하고, 문제가 있으면 조용히 넘어가지 않고 알려 줍니다.
Rust · 명령줄 도구

내 컴퓨터에서 직접 실행하기

Rust와 Cargo가 설치되어 있다면 저장소를 내려받아 바로 빌드할 수 있습니다. 이미지와 작업 정보는 이 과정에서도 내 컴퓨터 안에만 남습니다.

현재 서명된 macOS 바이너리는 배포하지 않습니다. 아래 안내에서 소스 빌드 방법을 확인하세요.
설치 안내 보기 
perfectpixel inspect art/input.png
perfectpixel upscale sprites/idle.png --out sprites/idle@2x.png --scale 2
perfectpixel psd --request image-psd-request.json
perfectpixel vector icon.png --out icon.svg --preset flat-icon --profile compact
